Connect AniList

Connect the same account you use on AniList. Episodes are marked watched after you pass 80% of the video, including seeking.

  1. Get AniList token and authorize Ani-QW.
  2. Copy the token shown by AniList and paste it below.

Linux helper

Build the helper and run ani-qw install chromium, then load this extension unpacked. If Play cannot connect, run ani-qw doctor chromium.

Playback continues when Chromium closes. A 20 GiB cache keeps recent downloads; sharing stops when playback ends.
