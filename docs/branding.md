# Branding assets

Ani-QW means **AniList Quick Watch**.

The icon in `icon.png` and `extension/icon.png` was generated with the built-in image generation tool. The extension public key and stable ID are unchanged.

Prompt: Minimal professional AQ lettermark for AniList Quick Watch; uppercase bold geometric sans-serif; cyan A and white Q with a short cyan tail; flat colors, transparent background, readable at toolbar size; no animals, stars, gradients, frames or additional text.

`docs/images/playback.jpg` is an actual extension UI capture with synthetic test data, rendered at twice the normal CSS scale (820 pixels wide). It contains no account details or real download information.
