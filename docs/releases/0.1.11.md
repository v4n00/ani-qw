# Ani-QW 0.1.11

## Playback fixes

- Re:ZERO Season 4 releases with repeated season annotations now qualify for automatic selection. Conflicting seasons still require manual selection.
- The main button stays on Starting while mpv buffers its first frames.
- Anime and non-anime navigation minimize the playback panel.
- Watched confirmation appears in the main status card alongside the player state.
- After successful watch synchronization, an aired next episode gets a Play next episode button and a ten-second countdown. Other closures retain the five-second countdown.
- Unaired shows no longer expose the dropdown.
- Closing AniList’s list editor refreshes the episode target without reloading the page.

## Preferences and installation

- Sharing during playback is configurable; turning it off hides upload speed. Small transfer rates now display in KiB/s.
- Preferences have clearer rows, with connection and update tools in a separate section.
- Check for updates compares the installed extension against the latest published GitHub release.
- The Bash installer offers detected native Chromium browsers and warns when ~/.local/bin is not in PATH. Explicit --browser and noninteractive installation remain supported.

## Release reliability

- CI retries dependency downloads, not failed tests.
- Helper, extension and release tag versions must agree before publication.
- Historical tags and commits remain intact.

Update both the Linux helper and the extension, then reload Ani-QW and AniList tabs. Source verification includes Go race tests, JavaScript tests, three isolated installer tests, 43 Chromium UI fixture checks, and controlled local torrent/mpv seeking. Live AniList account synchronization and the hosted release workflow require post-installation/release verification.
